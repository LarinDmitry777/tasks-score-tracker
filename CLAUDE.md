# ScoreFlow — правила для AI-моделей

Этот файл содержит обязательные правила для любой LLM-модели, работающей над проектом ScoreFlow.

## Проект

**ScoreFlow** — геймифицированный трекер итогов дня для мобильных устройств.
Стек: React + TypeScript + Vite + Zustand + CSS Modules.
Состояние хранится в `localStorage` через Zustand `persist` middleware.

---

## Обязательные правила

### 1. Экспорт и импорт любого состояния

**Любое новое состояние, добавляемое в `useStore`**, должно:

- Быть включено в функцию `exportState` — попадать в JSON-бэкап.
- Корректно восстанавливаться через `importState` с валидацией.
- Версия бэкапа (`version`) в `exportState` должна быть увеличена при изменении структуры данных, а в `importState` добавлена миграция для старой версии.

**Пример**: если добавляется новое поле `goals: Goal[]`, оно обязательно включается в payload `exportState` и проверяется при `importState`.

### 2. Mobile-first разработка

Приложение разрабатывается **прежде всего для мобильного браузера/PWA на iPhone**.

Требования к любому новому UI:
- Все интерактивные элементы (кнопки, чекбоксы) — минимум **44×44px** (Apple HIG).
- Никаких hover-only взаимодействий — основной сценарий это тач.
- Использовать `-webkit-tap-highlight-color: transparent` на кнопках.
- Учитывать `safe-area-inset-bottom` (нотч/home indicator на iPhone) через `env()`.
- Базовая ширина контента — **max-width: 480px**.
- Модальные окна реализуются как **bottom sheet** (снизу экрана), а не по центру.
- Шрифт и отступы должны быть читаемы без зума (`font-size` не меньше 14px).
- `viewport-fit=cover` уже задан в `index.html` — не убирать.

## Архитектурные соглашения

- **State**: Zustand store в `src/store/useStore.ts`. Не создавать параллельных хранилищ.
- **Стили**: CSS Modules (`.module.css`). Не использовать Tailwind, inline-стили только для динамических значений.
- **Типы**: все интерфейсы и типы — в `src/types.ts`.
- **Утилиты расчёта**: логика очков и множителей — в `src/utils/score.ts`.
- **Новые страницы**: создавать в `src/pages/`, подключать через TabBar в `App.tsx`.
